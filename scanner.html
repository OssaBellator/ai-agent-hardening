A dependency-free static scanner for repositories used with coding agents, MCP tools, CI automation, or other AI-assisted development workflows.

Run locally

Use as a GitHub Action

permissions:
  contents: read

steps:
  - uses: actions/checkout@v4
  - uses: OssaBellator/ai-agent-hardening@v1
    with:
      fail-on: high

The action requires only contents: read. Omit fail-on for advisory-only behavior, or choose high, medium, or any to fail CI at that threshold.

What it checks

  • common agent instruction/rules files;
  • MCP configuration files;
  • GitHub Actions workflow presence and selected high-authority patterns;
  • dependency/package manifests;
  • a small set of common credential/private-key patterns, reported by path and pattern class without printing the suspected value;
  • selected permission-bypass and workflow-authority signals.

What it does not do

The scanner never executes target repository code, installs target dependencies, authenticates to customer systems, or claims that an absence of matches means a repository is secure. It is a triage tool, not penetration testing or a security certification.
